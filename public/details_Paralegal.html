Key Features

Intelligent Query Generation

Uses Saul-7B Legal AI to analyze user questions, generates 3-5 optimized search queries, routes to optimal sources (CourtListener versus LexisNexis), and assigns priorities.

Hyper-Parallelized Scraping

100 concurrent workers with async/await throughout the pipeline, reaching 41.7 cases per second peak performance, which is 4-8x faster than baseline.

Multi-Source Integration

CourtListener provides 10.6M opinions via free API. LexisNexis enables premium case coverage through web scraping. Smart routing sends common cases to CourtListener and rare cases to LexisNexis.

GPU Acceleration

Uses AMD MI300X with 192GB VRAM, FAISS on GPU for fast similarity search, and sentence transformers for embeddings.

Testing

Run the complete system test with ./test_complete_system.sh.

  • Test 1: CourtListener API Access - verifies token and endpoints
  • Test 2: Query Generator - tests Saul-7B generation
  • Test 3: Intelligent Scraper - tests async scraping (5 cases)
  • Test 4: Hyper-Parallelized Orchestrator - tests full pipeline (60 cases)
  • Test 5: Performance Benchmark - tests concurrent research (135 cases)

Troubleshooting

  • Model not found: check vLLM server at http://localhost:8000/v1/models
  • API rate limit exceeded: verify COURTLISTENER_API_TOKEN and reduce max_concurrent
  • Module not found: run ./quick_fix_dependencies.sh
